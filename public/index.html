API Documentation

Project_nodejs.

A data-driven REST API for news posts and tags, built with Node.js, Express, and MySQL. Everything below returns JSON.

News

GET
/news All news posts, with pagination
▸

Returns a list of news posts, sorted by publish date (newest first) by default.

limit
query param, optional, default 10, max 100
offset
query param, optional, default 0
sort
query param, optional, one of title, author, published_at, created_at, prefix with - for descending

/news?limit=2&offset=0&sort=-title

GET
/news/search Search by title and content
▸

Searches both title and content (case-insensitive).

q
query param, required

/news/search?q=training

GET
/news/:id One news post, including its tags
▸

Returns a single news post, including its linked tags via the news_tag join table.

POST
/news Create a news post
▸

Body (JSON):

title
required, at least 5 characters
content
required
author
required, no digits allowed
published_at
required, format YYYY-MM-DD
PUT
/news/:id Update a news post
▸

Body (JSON): same fields and validation as POST /news.

DEL
/news/:id Delete a news post
▸

Deletes the news post, and its tag links, via ON DELETE CASCADE.

Tags

GET
/tags All tags
▸

Returns all tags, sorted alphabetically by default.

sort
query param, optional, -name for descending
GET
/tags/:id One tag
▸

Returns a single tag by id.

POST
/tags Create a tag
▸

Body (JSON):

name
required, no digits, must be unique
PUT
/tags/:id Update a tag
▸

Body (JSON): same fields and validation as POST /tags.

DEL
/tags/:id Delete a tag
▸

Deletes the tag, and its links to news posts.

Validation

News

title, content, author, and published_at are required. author may not contain digits. title must be at least 5 characters. published_at must use the format YYYY-MM-DD.

Tags

name is required, may not contain digits, and must not already exist.
